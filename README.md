# 환웅박물관 최후의 그랑프리

철거를 앞둔 곰인형 박물관을 지키는 **미션 레이싱 + 스토리 어드벤처**.
Unity 6000.3.18f1 / URP · Windows 단일 플레이 · 15~25분 분량.

---

## 이야기

박물관에 철거 통지서가 붙는다. 개발업자와 시의원이 그 자리에 리조트를 세우겠다고
생중계로 발표하고, 마지막 행사로 그랑프리를 연다. 거기에 곰 삼형제와 그들의 주인
정이감이 출전한다 — **1등이 목표가 아니라, 완주해서 사람을 모으는 것**이 목표다.

여덟 판을 도는 동안 증거가 하나씩 모이고, 아홉 번째 **결승**에서 그 증거를 들이민다.

## 조작

| 키 | |
|---|---|
| **W A S D** | 주행 · 걷기 |
| **SPACE** | 호핑 |
| **SHIFT** | 태엽(드리프트) |
| **TAB** | 둘러보기 ↔ 걸어다니기 |
| **E** | 말 걸기 · 문 열기 · 시계 보기 |
| **R** | 코스로 돌아가기 |
| **H** | 조작법 카드 |
| **V** | 화면 효과 끄기/켜기 |
| **ESC** | 일시정지 (다시 하기 · 로비로 · 계속) |

## 진행

- **임무 8판** — 완주 / 가속 발판 / 담장 안 긁기 / 제한시간 / 철거 자재 /
  곰인형 싣기 / 골든베어 광고 철거 / 무사고+시간. 한 판을 깨면 전시품 하나를 얻는다.
- **결승** — 여덟 개를 다 모으면 개발업자·시의원과 직접 겨룬다. 이기면 자유 주행이 열린다.
- 모은 것과 기록은 저장되고, 전시실·캠퍼스가 진행에 따라 조금씩 바뀐다.

## ⚠ 인터넷을 쓰는 곳이 한 군데 있습니다

로비 접수대의 **전자시계**는 현재 시각과 함께 **날씨**를 보여줍니다.
날씨는 [wttr.in](https://wttr.in) 에 요청해서 받아옵니다. 그래서:

- **도시를 지정하지 않으면 wttr.in 이 접속한 IP 주소로 위치를 짐작합니다.**
  즉 게임을 실행한 컴퓨터의 IP 가 그 서비스에 전달됩니다.
  (웹페이지를 여는 것과 같은 수준이며, 그 밖의 정보는 아무것도 보내지 않습니다.)
- 계정·키·개인정보를 수집하거나 저장하지 않습니다. 게임 밖으로 나가는 것은
  이 요청 하나뿐이고, **받아오는 것도 날씨 한 줄이 전부**입니다.
- **인터넷이 없어도 게임은 정상 동작합니다.** 날씨 칸만 비고 시계는 그대로 갑니다.

### 끄거나 바꾸는 법

로비 씬 `ReceptionDesk > DeskClock` 컴포넌트에서:

| 설정 | |
|---|---|
| `useOnlineWeather` **끄기** | 바깥으로 나가는 요청이 **0**이 됩니다. 날짜만 표시됩니다. |
| `city` 에 도시 적기 | 예: `Seoul`. IP 로 짐작하는 단계를 건너뜁니다. |

게임 안에서도 **시계에 다가가 `E`** 를 누르면 도시를 직접 입력할 수 있습니다.
도시를 적지 않았을 때는 먼저 **운영체제의 표준 시간대**로 나라를 추측하고,
그것도 알 수 없을 때만 IP 로 넘어갑니다.
