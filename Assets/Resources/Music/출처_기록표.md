## 픽사베이 음원을 쓸 때 적어둘 것

픽사베이는 출처 표기 의무가 없지만(Pixabay Content License), **제출용 기록표에는 적는 게 맞습니다.**
파일을 받을 때 이 세 가지를 같이 적어 두세요 — 나중에 찾으려면 못 찾습니다:

1. **곡 제목**
2. **업로더 이름**
3. **받은 날짜와 주소** (`pixabay.com/music/...`)

---

## 넣는 법 — 파일 이름이 곧 규칙

```
파일 이름 = 씬 이름         →  그 씬에서 나온다   (Title · Lobby · Track · Gallery · Campus)
파일 이름 = 씬 이름_완성    →  수집품 8개를 다 모은 뒤부터
파일 이름 = 이야기 장면 id  →  그 이야기가 도는 동안   (prologue · ch1 … )
파일 이름 = 장소 id         →  이야기 중 .At("…") 로 넘어간 뒤   (villain …)
```

`.wav` · `.mp3` · `.ogg` 다 됩니다. **곡이 없는 자리는 조용할 뿐 아무 것도 안 망가집니다.**
넣고 말씀해 주시면 제가 재서 크기와 루프 겹침을 맞추고 이 표에 한 줄 추가합니다.
