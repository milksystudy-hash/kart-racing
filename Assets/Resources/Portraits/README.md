# 초상화 넣는 곳

이야기 장면에 뜨는 2D 캐릭터 그림을 **이 폴더에** 넣으면 된다.
코드는 한 줄도 안 고쳐도 되고, 넣는 순간 회색 자리표시가 그림으로 바뀐다.

## 파일 이름 규칙

```
{누구}_{표정}.png
```

| 누구 | 표정 |
|---|---|
| `이감` `시우` `세운` `세진` `관장` `개발업자` `시의원` | `기본` `기쁨` `당황` |

예: `세진_기쁨.png`, `이감_기본.png`, `개발업자_당황.png`

- 기획서 §3.6 대로 **캐릭터당 세 장**이 목표다.
- `기쁨` / `당황` 이 아직 없으면 자동으로 `기본` 을 대신 쓴다.
  그러니 **`_기본` 일곱 장부터** 그리면 모든 장면이 일단 사람 얼굴로 채워진다.
- 악당의 `당황` 은 분노 표정으로 그려도 된다. 쓰이는 자리가 같다.

## 그림 규격

- **세로로 긴 그림** — 대략 가로 700 × 세로 900 px 언저리.
  화면에서는 높이가 화면의 약 40 % 로 줄어드니 그보다 크게 그릴 필요는 없다.
- **배경은 투명(알파)** 으로. 박물관 배경 위에 얹히는 그림이야.
- 인물은 **아래쪽에 발이 잘리게** 두는 게 자연스럽다 — 상반신~허벅지.
- 비율은 코드가 지켜준다. 가로세로가 달라도 안 찌그러진다.

## 유니티에서 한 번만 해줄 것

넣은 뒤 그 이미지를 클릭하고 인스펙터에서

- **Texture Type: `Sprite (2D and UI)`** 또는 그냥 기본값(Default)도 뜬다
- **Alpha Is Transparency** 체크

하면 테두리가 깨끗해진다.

## 누가 무슨 색인지

이름표 색은 `Assets/Scripts/Cast.cs` 에 모여 있다. 그림 색과 안 맞으면 거기 숫자만 바꾸면 된다.
