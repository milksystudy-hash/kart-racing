# 첫 화면 배경

`Title.png` 하나를 여기 넣으면 게임 첫 화면 배경이 된다.
**없으면 3D 중앙홀이 천천히 도는 게 배경이다** — 안 그려도 게임은 멀쩡하다.

## 크기

| | |
|---|---|
| 그리는 크기 | **2560 × 1440** (16:9) |
| 들어오는 크기 | 2048 × 1152 (임포터가 자동) |
| 파일 | PNG, `Title.png` |

가로세로만 **16:9** 면 되고 더 커도 된다 — 임포터가 긴 변을 2048 로 맞춘다.
16:9 가 아니면 `ScaleAndCrop` 이라 **여백 없이 꽉 채우고 넘치는 쪽을 자른다.**

## 어디를 비워야 하나 (가로·세로 %)

```
 0%                    50%                   100%
  ┌───────────────────────────────────────────┐ 0%
  │                                           │
  │        ┌───────────────────┐              │ 15%   ← 제목 현판
  │        │                   │              │
  │        └───────────────────┘              │ 38%
  │                                           │
  │              ┌─────────┐                  │ 56%   ← 게임 시작
  │              ├─────────┤                  │
  │              └─────────┘                  │ 74%   ← 나가기
  │                 ↑↓ ENTER                  │ 80%
  │                                           │
  └───────────────────────────────────────────┘ 100%
     ← 마음껏 →   가운데는 조용히   ← 마음껏 →
```

- **가로 25~75% · 세로 15~80%** 안에는 눈길을 끄는 디테일을 넣지 마라.
  어두운 하늘·벽·안개처럼 **조용한 것**이 온다.
- 캐릭터나 카트를 넣고 싶으면 **좌우로 비켜서**. 가운데는 글자 자리다.
- **아래로 갈수록 어둡게** 그리면 메뉴가 잘 읽힌다(코드도 같은 방향으로 살짝 누른다).

## 그리지 말 것

- **게임 제목 글자** — 이름이 아직 안 정해졌고, 코드가 현판에 얹는다.
  배경에 구우면 이름 바꿀 때마다 다시 그려야 한다.
- **메뉴 글자·버튼** — 코드가 그린다.
