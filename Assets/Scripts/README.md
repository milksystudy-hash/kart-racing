# 테스트 환경

## 씬 세 개

| 씬 | 키 | 뭐가 있나 |
| --- | --- | --- |
| `Scenes/Lobby.unity` | **F1** | 디저트 로비. 걸어다니며 캐릭터를 고르고 출발문으로 들어가면 레이스 시작 |
| `Scenes/Track.unity` | **F2** | 타원 트랙. 걸어서 둘러보다가 Tab 으로 카트를 탈 수 있다 |
| `Scenes/Testbed.unity` | **F3** | 아무것도 없는 회색 맵 + 크기 기준물. 블렌더에서 만든 걸 던져 넣고 확인하는 곳 |

셋 다 Build Settings 에 등록돼 있어서, 재생 중에 **F1 / F2 / F3** 로 왔다갔다 할 수 있어.
`F5` 는 지금 씬 다시 시작.

## 로비 — 환웅박물관 중앙홀

**걸어다니지 않는다.** 카메라가 홀 가운데를 중심으로 돌고, 마우스로 캐릭터를 고른다.

| 조작 | 동작 |
| --- | --- |
| 마우스 끌기 | 둘러보기 (회전) |
| 휠 | 확대·축소 |
| 클릭 | 캐릭터 선택 / 출발문 |
| `Enter` | 출발문과 같음 |

손을 떼고 5초 지나면 카메라가 천천히 돌기 시작해 (`Lobby Camera` 의 `Idle Delay` 로 조절).
천장은 일부러 안 덮었어 — 카메라를 위로 올리면 홀 안이 내려다보여.

### 들어 있는 것

참고 그림(곰인형 박물관 외관)의 재료를 실내로 옮겼어 — 청록 기와 띠, 크림 벽에 민트 허리
패널, 짙은 목재 기둥과 주춧돌, 석재 바닥, 석등 4개(점광원 포함), 그리고 바닥 한가운데
**발바닥 문양**. 기획서 §4.2 의 중앙홀 구성물인 **안내 데스크 · 대형 곰 조형물(빨간 리본
포함) · 출발 게이트 · 중계 화면**도 다 있어.

> 기획서 §4.4 는 기본색을 "짙은 남색"이라고 적었는데 참고 그림은 **청록**이야.
> 그림 쪽을 따랐어. 남색이 맞으면 `LobbySceneBuilder.cs` 의 `ColRoofTeal` 만 바꾸면 돼.

### 캐릭터 자리 6개

기획서 §3.5 대로 **이감·시우·세운·세진 4명은 선택 가능**, **개발업자·시의원 2명은 잠김**.
잠긴 자리는 받침대가 어둡게 나오고 클릭해도 선택되지 않아. 출발문도 막혀 있어서
캐릭터를 고르기 전엔 레이스가 시작되지 않아.

> 잠금은 `CharacterStand` 의 **`Locked` 체크박스**로 정해. 모델이 있냐 없냐와는 무관해.

**★ 네 캐릭터 FBX 를 넣는 곳:** 각 `Stand_N_...` 안의 **`ModelAnchor`**.
거기에 FBX 를 자식으로 끌어다 놓고 그 안의 `Placeholder` 캡슐을 지우면 끝. 코드는 안 고쳐도 돼.
`ModelAnchor` 가 받침대 윗면(y=0.48)에 있으니, FBX 원점이 규격서대로 **발밑(y=0)** 이면
위치가 저절로 맞아.

`SampleScene.unity` 는 유니티 템플릿이 만들어준 거야. 안 써. 지워도 되고 놔둬도 돼.

## 조작

**걸어다닐 때** — 네가 주인공의 눈이 되는 모드

| 키 | 동작 |
| --- | --- |
| `WASD` | 걷기 |
| 마우스 | 시점 |
| `Shift` | 달리기 |
| `Space` | 점프 |
| `F` | **자유 비행** — 벽을 통과하고 위아래로 난다. 맵을 위에서 볼 때 |
| `Space` / `Ctrl` | 비행 중 상승 / 하강 |
| `Tab` | 카트 타기 (트랙 씬에서만) |
| `Esc` | 마우스 커서 풀기 |

> 커서가 화면에 갇히면 **Esc**. 다시 잡으려면 화면 클릭.

**카트 탔을 때** — `WASD` 주행, `Space` 드리프트, `R` 리스폰, `Tab` 내리기

## 크기 기준물 (Testbed 씬)

블렌더에서 만든 게 실제로 얼마나 큰지 눈으로 재라고 놔둔 것들이야. 규격서 치수 그대로:

| 오브젝트 | 크기 |
| --- | --- |
| `Ref_1m_Cube` | 1m 정육면체 — 모든 크기의 기준 |
| `Ref_Human_1.7m` | 사람 키 |
| `Ref_Chibi_1.15m` | 치비 캐릭터 서 있는 키 |
| `Ref_Kart_1.5x1.1x0.55` | 카트 크기 |
| `Post_10m` ~ `Post_40m` | 10m 간격 거리 기둥 |

**쓰는 법:** 네 FBX 를 Testbed 씬에 끌어다 놓고, 기준물 옆에 세운 다음, `F` 로 날아서 위아래로 보면 돼. 너무 크거나 작으면 블렌더에서 고치는 게 맞아 — 유니티에서 스케일을 조정하지 마.

## 트랙을 없애고 싶으면

Track 씬의 `Track` 오브젝트를 고르고 인스펙터에서 **`Build On Awake` 체크를 끄면** 돼.
트랙이 안 생기고 빈 바닥만 남아. 지우지 않았으니 다시 켜면 그대로 돌아와.

코스 모양(`Radius X`, `Radius Z`, `Road Width`)도 거기서 바꿀 수 있어.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `FirstPersonController.cs` | 1인칭 걷기 · 시점 · 자유 비행 |
| `PlayerModeSwitcher.cs` | Tab 으로 걷기 ↔ 카트 전환 |

| `KartInput.cs` | 키보드 · 게임패드 입력 |
| `KartCamera.cs` | 카트 따라다니는 카메라 |
| `LapTracker.cs` · `Checkpoint.cs` | 랩 카운트 · 랩타임 |
| `TestHUD.cs` | 임시 화면 표시. 진짜 UI 만들 때 버릴 것 |
| `Editor/TestSceneBuilder.cs` | 씬 두 개를 다시 만드는 메뉴 (`Racing` 메뉴) |

> `Racing → 테스트 씬 두 개 다시 만들기` 는 씬을 **덮어쓴다.** 씬에 손으로 뭘 넣기 시작한 뒤에는 누르지 마.

## 주의

이 프로젝트는 **Input System 패키지 전용**이야 (`activeInputHandler: 1`).
옛날 방식인 `Input.GetAxis` / `Input.GetKey` 는 컴파일은 되지만 **실행할 때 에러가 난다.**
